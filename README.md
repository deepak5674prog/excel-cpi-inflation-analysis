The analysis covers:

* General Index
* Food & Beverages
* Health
* Transport
* Housing
* Fuel & Light
* Clothing

The project uses both descriptive and comparative analysis to understand how CPI values changed over time.

# 📈 Analysis 2 — General Index & Yearly Trend

The project analyzes the **General Index** across the period **2017–2023**.

### Analysis includes:

* Average General Index by year
* Year-wise comparison
* Annual growth
* Long-term CPI trend

### General Index

| Year | Average General Index |
| ---- | --------------------: |
| 2017 |            **133.39** |
| 2018 |            **138.67** |
| 2019 |            **144.13** |
| 2020 |            **153.33** |
| 2021 |            **161.42** |
| 2022 |            **172.08** |
| 2023 |            **177.57** |

### Key Observation

The General Index shows an overall upward trend from 2017 to 2023, indicating an increase in overall CPI levels during the analyzed period.

# 🦠 Analysis 4 — Pre-COVID vs Post-COVID

The project compares CPI indicators between **pre-COVID and post-COVID periods**.

### Comparison

| Period     |     Health | General Index | Food & Beverages |
| ---------- | ---------: | ------------: | ---------------: |
| Pre-COVID  | **148.95** |    **145.98** |       **147.25** |
| Post-COVID | **156.41** |    **154.84** |       **158.13** |

### Key Observation

The post-COVID period shows higher average values across the analyzed indicators compared with the pre-COVID period.

This provides a simple comparative view of how CPI levels changed across the two periods.

# 🛢️ Analysis 5 — Crude Oil & Inflation Relationship

The project investigates the relationship between:

* Crude Oil Prices
* Oil month-over-month change
* Transport month-over-month change
* General Index month-over-month change

Correlation analysis was used to examine the relationship between these variables.

### Excel Function Used

```text
CORREL()
```

The correlation analysis helps understand whether movements in crude oil prices are associated with changes in transport and General Index indicators.

> **Note:** Correlation indicates statistical association and does not by itself establish causation.
