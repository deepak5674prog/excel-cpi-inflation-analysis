# 📊 CPI Inflation Analysis | Excel Data Analytics Case Study

## 📌 Project Overview

This project is an **Excel-based data analytics case study** focused on analyzing **Consumer Price Index (CPI) and inflation trends** across different sectors and time periods.

The project uses historical CPI data to examine changes in the **General Index**, category-level inflation, food and beverage prices, health, transport, and other major expenditure groups.

The analysis was performed using **Microsoft Excel** with data cleaning, transformation, formulas, pivot tables, percentage calculations, correlation analysis, and comparative analysis.

# 📈 Analysis 2 — General Index & Yearly Inflation

The second analysis examines the **General Index** across different years.

# 🦠 Analysis 4 — Pre-COVID vs Post-COVID

This analysis compares CPI-related indicators between **pre-COVID and post-COVID periods**.

| ---------- | -----: | ------------: | ---------------: |
| Pre-COVID  | 148.95 |        145.98 |           147.25 |
| Post-COVID | 156.41 |        154.84 |           158.13 |

The post-COVID averages are higher across the analyzed indicators, showing an increase in the CPI levels compared with the pre-COVID period.
